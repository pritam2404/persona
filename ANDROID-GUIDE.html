Persona: Android App + Play Store

Live app: https://pritam2404.github.io/persona/  ·  Code: github.com/pritam2404/persona

Level 1: Aaj hi phone pe (2 minute, free)

  1. Phone pe Chrome mein kholo: https://pritam2404.github.io/persona/
  2. Upar-right ⋮ menu → Add to Home screen / Install app → Install.
  3. Home screen pe Persona ka icon aa jayega. App ki tarah full screen khulta hai aur offline bhi chalta hai.
Laptop wala data phone pe apne aap nahi aata. Laptop pe Export karo, file phone pe bhejo, phone pe Import karo.

Level 2: Asli APK file (15 minute, free)

PWABuilder (Microsoft ki free website) tumhari live site se Android app bana deti hai. Laptop pe kuch install nahi karna.

  1. pwabuilder.com kholo → URL daalo https://pritam2404.github.io/persona/ → Start.
  2. Report aayegi. Agar koi red warning ho, uska screenshot mujhe bhejo.
  3. Package for stores → Android → Generate Package. Options mein:
    • Package ID: io.github.pritam2404.persona (baad mein kabhi badal nahi sakte)
    • App name: Persona, Version: 1.0.0
    • Signing key: New (PWABuilder bana dega)
  4. Ek .zip download hogi. Use projects\persona\android-package\ mein unzip karo. Ye folder git mein nahi jaata.
Zip ki fileKis kaam ki
*.apkPhone pe seedha install karke test karne ke liye
*.aabPlay Store pe upload karne ke liye
signing.keystore + signing-key-info.txtApp ki "chaabi" (signing key)
assetlinks.jsonApp ke upar ka URL bar hatane ke liye (Level 2.5)
Bahut zaroori: signing.keystore aur uska password Google Drive ya pendrive mein bhi backup karo. Ye kho gaya toh Play Store pe app ka update kabhi nahi daal paoge. Kisi ko mat bhejna, mujhe bhi nahi. Ye kisi bhi repo mein upload nahi hona chahiye.

APK phone pe install karna

  1. APK file phone pe bhejo (USB cable, ya Drive).
  2. Files app mein us APK pe tap karo. Phone poochega "Install unknown apps"? Allow karo (sirf Files app ke liye).
  3. Install. Ho gaya.

Level 2.5: URL bar hatana

Pehli baar app ke upar ek chhota browser bar dikhega. Use hatane ke liye Android ko proof chahiye ki app aur website ek hi owner ki hain. Iske liye assetlinks.json ko https://pritam2404.github.io/.well-known/assetlinks.json pe daalna padta hai. Ye domain ke root pe hota hai, persona folder mein nahi.

Ye main kar dunga: mujhe batao ki zip unzip ho gaya. Main android-package\assetlinks.json padh ke (usme sirf public fingerprint hota hai, koi secret nahi) pritam2404.github.io naam ka repo bana ke daal dunga.

Videos phone pe kaise aayenge

  1. Colab notebook phone ke Chrome mein bhi chalta hai. Aakhri cell video seedha phone ke Downloads mein save karta hai. Laptop pe banaya ho toh WhatsApp/Drive se phone pe bhej do.
  2. Persona → Videos tab → + Video add karo → video chuno.
  3. App mein Play karo. Save / Share se gallery, Drive ya WhatsApp mein bhejo.

Videos sirf phone ke andar rehte hain. App uninstall karoge ya data clear karoge toh videos bhi chale jayenge, isliye zaroori videos ki copy gallery mein rakho.

App update kaise hoga

Code badla → push → GitHub khud site update karta hai → installed app agli baar kholne pe naya version le leta hai. Play Store pe naya .aab tabhi daalna padta hai jab icon, naam ya package badle.
